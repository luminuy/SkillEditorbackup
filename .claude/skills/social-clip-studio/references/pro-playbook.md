## 1. Pro vs มือสมัครเล่น
แนวคิดหลัก: **ทุกวินาทีต้อง "จ่ายค่า" ให้คนดูอยู่ต่อวินาทีถัดไป** (retention mindset) — ถ้าวินาทีไหนไม่ให้ข้อมูลใหม่ ภาพใหม่ หรือคำถามใหม่ มันคือจุดที่คนปัดทิ้ง

| มือสมัครเล่น | Pro |
|---|---|
| ตัดตามลำดับที่ผู้พูดพูด | เรียงใหม่ตาม **ความอยากรู้** — เอาพีคขึ้นก่อน (cold open) แล้วค่อยเล่า |
| เริ่มจาก "สวัสดีค่ะ" / โลโก้ / intro | วินาทีแรกคือคำตอบ คำถาม หรือภาพเปิดไพ่ |
| ใส่เอฟเฟกต์เพราะมี | เอฟเฟกต์ทุกตัวมีหน้าที่: เน้นคำ, ซ่อนรอยตัด, หรือบอกว่า "ตรงนี้สำคัญ" |
| ซับยาวเต็มประโยค | ซับสั้น 2–4 คำ อ่านทันในจังหวะพูด คำสำคัญมีสี |
| เสียงดังเบาไม่เท่ากัน, มีเสียงลม/เสียงห้อง | เสียงพูดสะอาด ดังสม่ำเสมอ ดนตรีหลบเสียงพูด (ducking) |
| แต่ละคลิปหน้าตาไม่เหมือนกัน | เทมเพลตเดียวทั้งซีรีส์ คนจำได้ใน 1 วินาทีว่าเป็นช่องไหน |
| ดูยอดวิวอย่างเดียว | อ่าน retention graph ว่าคนหลุดวินาทีไหน แล้วแก้ preset |

## 2. โครงคลิปที่ชนะ → map กับ plan
| ช่วง | เวลาโดยประมาณ | หน้าที่ | ฟิลด์ใน plan |
|---|---|---|---|
| **Hook** | 0–1.5s | หยุดนิ้ว: ใคร + ได้อะไร + ความอยากรู้ | `segments[0]` (cold open, `sort:false`), `hook`, `hook_seconds`, `fx` punch/flash ที่เฟรมแรก, `sfx` pop |
| **Context** | ≤ 3s | บอกว่าคลิปนี้ของใคร (ราศี/กอง/โสด-มีคู่) | `labels` badge `{"text":"กอง 2"}`, hook box ค้าง, ซับ |
| **Build** | กลางคลิป | เปิดไพ่ทีละใบ เล่าเหตุผล | `segments` หลายช่วง, `labels` การ์ด, `transition`, per-segment `zoom` สลับ |
| **Re-hook** | ~40–60% ของคลิป | ปลุกคนที่เริ่มเบื่อ: open loop ใหม่ | `transition_in` dip/flashfade, `sfx` riser, `fx` zoom, badge "แต่ใบสุดท้าย…" |
| **Payoff** | ท้ายคลิป | เฉลย/ข้อความหลักที่แคปไปแชร์ได้ | `fx` stars/glow + `sfx` riser→impact/chime, `emphasis` |
| **Loop / CTA** | 1–3s สุดท้าย | ส่งต่อไปดูซ้ำหรือคอมเมนต์ | `cta` (หรือ `kind` → `cta_by_kind`), segment สุดท้ายที่ต่อกับประโยคแรกได้ |

ตัวอย่างคลิปราศี (cold open):
```jsonc
"sort": false,
"segments": [
  {"start": 412.3, "end": 415.0, "zoom": 1.18},          // "ไพ่ The Sun ออกมาเลย ชาวเมษ!"  ← พีคขึ้นก่อน
  {"start": 380.2, "end": 398.6, "transition_in": "dip"}, // "มาดูกันว่าทำไม… ใบแรกคือ…"
  {"start": 398.9, "end": 425.0, "zoom": 1.0}             // เล่าต่อจนเฉลย + ข้อความปิด
]
```
- เลือกกอง: hook = "กอง 2 ใครกำลังจะกลับมา" + ภาพ 3 กองนิ่ง 0.5s ให้คนหยุดเลือก แล้วตัดเข้ากองทันที
- ไลฟ์: ตัดช่วงตอบคำถามที่เป็นเรื่องทั่วไป เปิดด้วยคำตอบ ("คนนี้ยังไม่ลืมคุณค่ะ") ไม่ใช่คำถามจากแชต
- re-hook ทาโรต์ที่ได้ผลบ่อย: "แต่ใบที่ทำให้ไพ่ทั้งชุดเปลี่ยนคือใบนี้…", "ส่วนเรื่องที่คุณกังวลอยู่…"

## 3. Hook craft
Hook ที่ดีคือ **3 ชั้นพร้อมกัน** ในวินาทีแรก:
- **Visual hook**: เฟรมแรกมีการเคลื่อนไหว/หน้าคน/ไพ่หงาย — ไม่ใช่โต๊ะว่างหรือหน้าจอดำ; `fx` punch หรือ flash ที่เฟรมแรกช่วยได้
- **Verbal hook**: ประโยคแรกที่ได้ยินคือพีค (ตัดคำเกริ่นทิ้ง, หรือ cold open)
- **Text hook**: `hook` บนจอ ≤ ~40 ตัวอักษร, 1–2 บรรทัด, บอก "ใคร + ได้อะไร" — **ไม่ซ้ำ** กับคำที่พูด แต่เสริมกัน

Hook pattern ภาษาไทยสำหรับทาโรต์ (เขียนเป็นข้อความบนจอหรือเลือกประโยคพูดที่ตรง):
| # | Pattern | ตัวอย่าง |
|---|---|---|
| 1 | เรียกตัว + ผลลัพธ์ | "ราศีเมษ คนที่คิดถึงกำลังจะทักมา" |
| 2 | Open loop | "ไพ่ใบสุดท้ายของกอง 2 ไม่มีใครคาดคิด" |
| 3 | คำถามตรงใจ | "เขายังคิดถึงคุณอยู่ไหม? ไพ่ตอบแล้ว" |
| 4 | เตือนเบา ๆ (ไม่ขู่) | "ชาวกันย์ ไพ่ขอเตือนเรื่องเดียว" |
| 5 | ตัวเลข/รายการ | "3 เรื่องที่ราศีตุลย์จะได้ยินเดือนนี้" |
| 6 | Card reveal cold open | ภาพพลิกไพ่ + "The Lovers ออกมาเลย" |
| 7 | Pattern interrupt | "หยุดก่อน! ถ้าคุณเลือกกอง 3" |
| 8 | Identity / แท็กเพื่อน | "ใครเป็นราศีสิงห์ แท็กมาดูด้วยกัน" |
| 9 | Contrast | "งานยังเหนื่อย แต่เรื่องรักกำลังเปิด" |
| 10 | Timing | "อีก 7 วันนี้ ราศีมังกรจะได้ข่าว…" (ใช้ "มีแวว" ไม่การันตี) |
| 11 | ข้อความจากจักรวาล | "ถ้าคลิปนี้เด้งมาหาคุณ นี่คือข้อความของคุณ" |
| 12 | Before/after อารมณ์ | "จากคนที่รอ กลายเป็นคนที่ถูกตามหา" |

สิ่งที่ฆ่า hook: "สวัสดีค่ะ/วันนี้เรามา…", โลโก้/intro animation, slow zoom-in จากภาพนิ่ง, เริ่มกลางการสับไพ่, hook บนจอที่คลิกเบตเกินเนื้อหา (ผิด compliance + คนปัดทิ้งเมื่อรู้ตัว), ตัวหนังสือเล็ก/ยาวเกินอ่านทันใน 1.5s, เสียงเงียบ/ลมหายใจก่อนพูดคำแรก
compliance: ห้ามการันตี เลขเด็ด ขู่ให้แชร์ — ดู `tarot-reading-knowledge/references/compliance-th.md`

## 4. Pacing — ตัวเลขตั้งต้น
| ปัจจัย | viral / dynamic | calm / mystic (ข้อความจักรวาล, ฮีลใจ) | ปรับที่ |
|---|---|---|---|
| ภาพเปลี่ยน (ตัด/ซูม/ป้าย/fx) | ทุก ~1.5–3s | ทุก ~3–5s (ยอมนิ่งได้ถ้าเสียงดึงอยู่) | `style`, `fx`, per-segment `zoom` |
| คำต่อการ์ดซับ | 2–4 คำ, 1 บรรทัด | 4–7 คำ, 1–2 บรรทัด | `captions.max_words`, `captions.lines` |
| รูเงียบหลังตัด | pad ~0.1–0.15s | pad ~0.2–0.35s (ให้หายใจ) | `remove_silence` + silence config |
| ความเร็ว | 1.05–1.1 ถ้าผู้พูดช้า | 1.0 (อย่าเร่งเสียงนุ่ม) | `speed` (ห้าม > 1.15) |
| transition | cut/punch/whip/zoom | crossfade/dissolve/dip | `transition`, `transition_in` |
| ซับ | `pop`/`bold` + `caption_anim` pop/bounce | `karaoke`/`highlight` + fade | `captions.style`, `caption_anim` |
- คลิป < 30s ใช้พลังเต็มได้; คลิป 45–75s ต้องมี re-hook อย่างน้อย 1 ครั้ง และ "หายใจ" หลังพีค 1–2s ไม่งั้นคนเหนื่อย
- ไพ่หนัก (The Tower, Death, 10 ดาบ): ลดจังหวะลง ไม่ shake/impact — ความเร็วต้องตามอารมณ์เนื้อหา ไม่ใช่เร็วสุดเสมอ
- `remove_fillers` ตัด "เอ่อ/อ่า/แบบว่า" — ตรวจด้วยหูว่าไม่ไปตัดคำที่เป็นเนื้อหา (เช่น "แบบ" ที่แปลว่า "ลักษณะ")

## 5. เทคนิคการตัด
- **ตัดที่ขอบคำ** ไม่ใช่กลางพยางค์: ใช้เวลาจาก `transcript.json` (`words[].start/end`) หรือ `find`; เผื่อ ~0.03–0.08s ก่อนต้นคำเพื่อไม่กินพยัญชนะต้น (โดยเฉพาะ ส/ฉ/ฟ ที่เสียงเบา)
- **ลบ** filler, false start ("ไพ่ใบ… ไพ่ใบแรกนะคะ" → เก็บแค่ครั้งที่พูดจบ), ประโยคซ้ำ, "เดี๋ยวนะคะ" ระหว่างสับไพ่
- **Jump cut + punch-in สลับกัน**: ในเทคเดียว (talking head) ถ้าตัดติดกันด้วยเฟรมเดิม ภาพจะกระตุก → สลับ `zoom` 1.0 ↔ 1.12–1.2 (และขยับ `x`/`y` เล็กน้อย) ทุกรอยตัด ห้าม jump cut บน framing เดิมสองครั้งติด
- **J-cut**: เสียงของช็อตถัดไปเข้ามาก่อนภาพ (ได้ยิน "ใบต่อไปคือ…" ขณะยังเห็นกองไพ่) → ลื่นและดึงความสนใจไปข้างหน้า
- **L-cut**: ภาพเปลี่ยนแล้วแต่เสียงช็อตก่อนยังพูดต่อ (ตัดไปไพ่ close-up ขณะผู้อ่านยังอธิบาย) → ใช้เป็น B-roll ในตัว
- engine ตัดเสียง+ภาพพร้อมกัน (straight cut); J/L-cut ทำใน NLE หลัง `nle <slug>` (FCPXML ชี้ไฟล์ต้นฉบับ มี handles ให้ลากเสียงล้ำได้ — ข้อ 14) หรือจำลองด้วย `stack` (หน้า+ไพ่)
- **B-roll** ในทาโรต์ = มือพลิกไพ่, close-up ใบไพ่, กองไพ่ทั้ง spread — ใช้ `reframe` crop `x`/`y` คนละจุดของเฟรมเดียวกันเป็น "มุมกล้องที่สอง"
- **Match energy**: รอยต่อสองช่วงที่ต่างพลัง (ตื่นเต้น → นิ่ง) ใส่ `dip`/`crossfade`; พลังเท่ากันใช้ cut/punch
- Montage จากหลายช่วงของไลฟ์: ต้องฟังรู้เรื่องโดยไม่รู้บริบทเดิม — ถ้าต้องอธิบายด้วย badge เกิน 1 ป้าย แปลว่าช่วงนั้นไม่จบในตัว

## 6. ซับแบบช่องใหญ่
- ขนาด: ตัวหนา อ่านได้บนมือถือที่ความสว่างต่ำ (Kanit Bold/ExtraBold + outline/เงา) — ปรับใน `channel.config.json` ไม่ใช่ต่อคลิป
- ตำแหน่ง: ค่าเริ่มต้น captions y≈0.68, hook 0.15, labels 0.29 — หลบ safe zone: บน ~10%, ล่าง ~20%, ขวา ~12% (ปุ่ม like/comment)
- 2–4 คำต่อการ์ดสำหรับคลิปพลังสูง; คำสำคัญ 1 คำต่อการ์ดเป็นสี `brand.emphasis` (`emphasis`: ชื่อไพ่, "เนื้อคู่", "ข่าวดี") — ถ้าทุกคำมีสี เท่ากับไม่มีคำไหนเด่น
- **ห้ามเบิร์นอิโมจิ** (libass แสดงไม่ได้ + ดูถูก) — อิโมจิไปอยู่ในแคปชันโพสต์แทน
- Thai line-breaking pitfalls:
  - ภาษาไทยไม่มีเว้นวรรค → ตัดบรรทัดต้องใช้ word segmentation (pythainlp) ห้ามตัดตามจำนวนตัวอักษร
  - อย่าแยกชื่อไพ่/ชื่อราศี/คำประสม ("ราชินี|ถ้วย", "ราศี|เมษ") และตัวเลขกับหน่วย ("กอง|2")
  - คำลงท้าย "ค่ะ/นะคะ/ครับ" อย่าโดดอยู่การ์ดเดียว — รวมกับการ์ดก่อนหน้าหรือตัดทิ้งจากซับ
  - สระบน/วรรณยุกต์ซ้อน (เช่น "ที่", "น้ำ") ต้องมี line spacing พอ ไม่ชนบรรทัดบน/hook box
- ซับต้องตรงเสียง 100%: ชื่อไพ่ผิด = ดูไม่มืออาชีพทันที → `fix` ก่อน render
- ทั้งซีรีส์ใช้ `captions.style` + `caption_anim` + สี เดียวกัน (`plain` ไว้กรณีพิเศษเท่านั้น)

## 7. Sound design
ลำดับความสำคัญ: **เสียงพูดสะอาด > ดนตรี > เอฟเฟกต์ > ภาพสวย** — คนดูทนภาพธรรมดาได้ แต่ไม่ทนเสียงแย่
| Layer | ระดับคร่าว ๆ | หมายเหตุ |
|---|---|---|
| Voice | อ้างอิง (target รวม −14 LUFS, true peak ≤ −1.5 dBTP ตาม config) | `voice_enhance` ลดเสียงรบกวน; ห้าม clip |
| Music bed | ต่ำกว่าเสียงพูดชัดเจน, ducked ใต้เสียงพูด | `music` + `music_volume` (~0.08–0.15); ใช้เฉพาะเพลงมีสิทธิ์ |
| SFX | เบากว่าเสียงพูด (engine ตั้ง ~−8 ถึง −15 dB) | `sfx`, `sfx_map`, `sfx_enabled` |
- whoosh / whoosh-soft บน transition ที่มีการเคลื่อนที่ (zoom/whip/slide); cut ธรรมดาไม่ต้องมีเสียง
- **riser → impact** เข้าจังหวะเฉลย: riser `offset` −1.0 ถึง −1.5s ก่อนเปิดไพ่, impact/chime/sparkle ตรงเฟรมเปิด; สาย calm ใช้ shimmer/chime แทน impact
- pop/click สำหรับ hook box/badge ขึ้นจอ — ไม่ต้องใส่ทุกป้าย
- อย่า over-SFX: rule of thumb ~1 เสียงต่อ 3–5s ใน dynamic; ถ้าเสียงเอฟเฟกต์ทับพยางค์สำคัญ ให้เลื่อนหรือตัดออก
- −14 LUFS คือเป้าที่ editor ใช้กันแพร่หลายสำหรับ social; แพลตฟอร์มอาจ normalize ต่างกัน — ตรวจด้วย `qa` เสมอ
- เพลงติดลิขสิทธิ์: ไม่ฝังในไฟล์ ปล่อย `music` ว่างแล้วใส่ในแอปตอนโพสต์

## 8. สีและ finishing
- `look` หนึ่งแบบต่อซีรีส์: `clean` (ดวงราศีทั่วไป) · `warm` (ความรัก/ฮีลใจ) · `mystic` (ข้อความจักรวาล, ไลฟ์กลางคืน) · `moody` (ไพ่หนัก, ใช้น้อย) · `vibrant` (viral สั้น) · หรือ `lut` (.cube) ของแบรนด์
- **Skin tone มาก่อน**: หน้าผู้อ่านไพ่ต้องเป็นสีผิวธรรมชาติ; mystic = ม่วง/น้ำเงินที่เงาและพื้นหลัง ไม่ใช่ย้อมหน้า และอย่า crush เงาจนตา/หน้ามืด
- ไพ่ต้องอ่านสีออก (ถ้วยน้ำเงิน, ไม้เท้าแดง-ส้ม) — LUT ที่เพี้ยนไพ่จนดูไม่ออก = ไม่ผ่าน
- ภาพจากมือถือ: denoise เบา ๆ ก่อน sharpen; sharpen แค่นิดเดียว (halo รอบตัวอักษร/ขอบหน้าบอกว่าเกิน); vignette เบา
- สเปก export ตั้งต้น: 1080×1920, H.264 (High), fps ตามต้นฉบับ (25/30; ไม่แปลงเป็น 60 เอง), yuv420p, AAC 48 kHz stereo, bitrate วิดีโอ ~10–20 Mbps — ตรวจด้วย `qa`

## 9. ความสม่ำเสมอของซีรีส์/แบรนด์
- ล็อกใน `channel.config.json`/preset: hook box, ฟอนต์, สี, ตำแหน่งซับ, watermark, progress bar, `effects.style`, `look` — ต่อคลิปแก้แค่เนื้อหา
- โครงเดียวกันทุกตอน: hook box ตำแหน่งเดิม → badge ราศี/กอง → การ์ดไพ่ lower-third → CTA เดิม — คนเห็น 1 วินาทีต้องรู้ว่าช่องไหน
- ชื่อเรียกคงที่: "กอง 1/2/3" ไม่ใช่สลับ "กองซ้าย/กอง A"; ชื่อไพ่ไทยจาก `name_th`
- ซีรีส์ 12 ราศี: ทุกคลิปยาวใกล้กัน, ใช้ `kind:"zodiac"` ให้ CTA ตรงกัน, เรียง id ตามความแรงไม่ใช่ตามลำดับราศี
- เปลี่ยนเทมเพลตเมื่อข้อมูลบอก (ข้อ 11) ไม่ใช่เพราะเบื่อ

## 10. Loop ending & rewatch
- ประโยคสุดท้ายควร "ป้อน" กลับเข้าประโยคแรก: จบด้วย "…และนี่คือเหตุผลที่" → วนกลับไป hook "ไพ่ The Sun ออกมาเลย"
- ตัดท้ายทันทีหลังคำสุดท้าย (ไม่มีเฟรมดำ/เฟดยาว/เงียบ) — ความเงียบท้ายคลิปบอกคนว่า "จบแล้ว ปัดได้"
- CTA ที่ไม่ฆ่า loop: สั้น (≤ 2s), ขึ้นทับขณะผู้พูดยังพูด ไม่ใช่หน้าจอ CTA แยก; ใช้คำถามชวนคอมเมนต์ ("ใครได้กองนี้ พิมพ์ 'รับ'") แทน "อย่าลืมกดติดตาม" ยาว ๆ
- rewatch hooks: เปิดไพ่เร็ว ๆ ให้คนย้อนดูว่าใบอะไร, ข้อความสำคัญขึ้นจอพอให้ "แคปหน้าจอ"
- ห้าม CTA ขู่/บังคับแชร์ ("แชร์ไม่งั้นโชคร้าย") — ผิด compliance

## 11. A/B test & learning loop
- ทำ 2 variant ต่อคลิปสำคัญ: เหมือนกันทุกอย่าง ต่างแค่ **hook** (ข้อความบนจอ หรือ `segments[0]` cold open vs เปิดตรง) → id `01a`/`01b`
- โพสต์คนละวันเวลาใกล้กัน หรือคนละแพลตฟอร์ม — ผลเป็นสัญญาณ ไม่ใช่ข้อพิสูจน์ (ช่วงเวลา/เทรนด์/เนื้อหาเป็นตัวแปรปน); ต้องเห็นซ้ำหลายรอบก่อนเปลี่ยน preset
- อ่าน retention graph:
  | รูปกราฟ | แปลว่า | แก้ที่ |
  |---|---|---|
  | ร่วงหนักใน 0–3s | hook ไม่ทำงาน | `hook`, cold open, เฟรมแรก |
  | ไหลลงเรื่อย ๆ | pacing ช้า | `speed`, silence pad, `captions.max_words`, fx ถี่ขึ้น |
  | หน้าผาช่วงกลาง | ช่วงเล่ายืด/เปลี่ยนหัวข้อ | ตัดช่วงนั้น, ใส่ re-hook |
  | มี bump ขึ้น | คนย้อนดู (จุดดี) | ทำแบบนี้ซ้ำในคลิปอื่น |
  | จบ > 100% / ต่อเนื่อง | loop ได้ผล | เก็บโครงจบนี้เป็นแม่แบบ |
- บันทึกผล (hook, style, ความยาว, % ดูถึง 3s, avg watch time) → ปรับค่าใน preset/`channel.config.json`; ดูห่วงโซ่ feedback ใน `external-addons.md`

## 12. Pro QA checklist
- [ ] เฟรมแรกไม่ใช่ภาพนิ่ง/ดำ, ไม่มี "สวัสดีค่ะ" หรือโลโก้ใน 3s แรก
- [ ] Hook บนจอ ≤ ~40 ตัวอักษร อ่านทันใน 1.5s และตรงกับเนื้อหาจริง
- [ ] บอก "ใคร" (ราศี/กอง/โสด-มีคู่) ภายใน 3s
- [ ] ไม่มีช่วงที่ภาพนิ่งเกินเป้า style (viral ~2.5s, dynamic ~4s)
- [ ] ไม่มี jump cut บน framing เดิมติดกัน
- [ ] ทุกรอยตัดอยู่ที่ขอบคำ ไม่กินพยัญชนะต้น/ท้าย
- [ ] ไม่มี filler/false start/ประโยคซ้ำหลงเหลือ
- [ ] มี re-hook ในคลิป > 40s
- [ ] ชื่อไพ่/ราศีในซับและ label ถูกต้อง (`cards --search`)
- [ ] ซับไม่ตัดบรรทัดกลางคำ, ไม่มีคำลงท้ายโดดเดี่ยว, ไม่มีอิโมจิ
- [ ] ซับ/hook/CTA อยู่ใน safe zone ไม่ชนปุ่มแอปด้านขวา/ล่าง
- [ ] คำเน้นสีไม่เกิน ~1 คำต่อการ์ด
- [ ] แฟลช/ประกายไม่บังหน้าหรือทำให้ตัวหนังสืออ่านไม่ออก
- [ ] loudness ~−14 LUFS, true peak ≤ −1.5 dBTP, ไม่มี clip/เสียงแตก
- [ ] ดนตรี duck ใต้เสียงพูด, sfx ไม่ทับคำสำคัญ
- [ ] เพลงมีสิทธิ์ใช้ (หรือเว้นว่างให้ใส่ในแอป)
- [ ] สีผิวธรรมชาติ, look ตรงกับซีรีส์
- [ ] จบทันทีหลังคำสุดท้าย, CTA สั้นไม่ฆ่า loop
- [ ] ความยาวเหมาะแต่ละ `platforms` (`plan-check`/`qa` ไม่มี ERROR)
- [ ] compliance: ไม่การันตี ไม่เลขเด็ด ไม่ขู่แชร์ ไม่มีข้อมูลส่วนตัวผู้ชมไลฟ์
- [ ] ดูรอบสุดท้ายบนมือถือจริง เสียงเปิด 1 รอบ ปิดเสียง 1 รอบ (เข้าใจได้จากซับอย่างเดียว)

## 13. Anti-patterns
| อย่าทำ | ทำแทน |
|---|---|
| เปิดด้วย "สวัสดีค่ะ วันนี้เรามาดู…" | cold open ที่ประโยคพีค (`sort:false`) |
| slow zoom-in จากภาพนิ่ง 2 วินาทีแรก | punch/flash ที่เฟรมแรก + เสียงพูดทันที |
| ใส่ shake/glitch/impact ทุกรอยตัด | เก็บเอฟเฟกต์แรงไว้ที่เปิดไพ่/เฉลย |
| transition พิเศษ (circle/pixelize) หลายครั้ง | ≤ 1 ครั้งต่อคลิป ที่เหลือ cut/zoom |
| ซับเต็มประโยค 2 บรรทัดในคลิป viral | 2–4 คำ, `pop`/`bold` |
| ทุกคำมีสี | 1 คีย์เวิร์ดต่อการ์ด |
| ตัดเงียบจนหายใจไม่ทัน (pad 0) | pad ~0.1–0.15s (calm มากกว่านั้น) |
| speed 1.2 ให้สั้นลง | ≤ 1.1 แล้วตัดเนื้อหาที่ไม่จำเป็นแทน |
| hook คลิกเบต "รวยแน่ 100%" | "มีแววข่าวดีเรื่องเงิน" |
| impact/shake ตอนไพ่ The Tower | `calm`/`dynamic`, chime เบา ๆ |
| LUT ย้อมหน้าม่วง | mystic ที่พื้นหลัง, skin tone ธรรมชาติ |
| เพลงดังกลบเสียงพูด | `music_volume` ต่ำ + ducking |
| เฟดดำ 2 วินาทีท้ายคลิป | ตัดจบที่คำสุดท้าย ต่อ loop ได้ |
| เปลี่ยนฟอนต์/สีทุกคลิป | เทมเพลตเดียวทั้งซีรีส์ |

## 14. macOS pro workflow
เลือกทาง:
- **Ship engine render** เมื่อ: ซีรีส์เทมเพลต (12 ราศี, เลือกกอง), ผ่าน `qa`, ไม่ต้องการ J/L-cut หรือ B-roll ภายนอก — เร็วและสม่ำเสมอที่สุด
- **Finish ใน NLE** เมื่อ: ต้องการ J/L-cut, B-roll จากไฟล์อื่น, color grade ละเอียด, ซ่อมเสียงหนัก, หรือคลิปเรือธงของสัปดาห์
- **CapCut kit** (`capcut <slug> --clip ID`) เมื่อ: ผู้ใช้อยากใช้ฟอนต์/เอฟเฟกต์/เพลงเทรนด์ในแอป
- **NLE hand-off**: `python3 -m clipstudio nle <slug> [--clip ID]` → `projects/<slug>/nle/`: `<slug>.fcpxml` (1 vertical project ต่อคลิป, markers ตอนเปิดไพ่/fx/sfx, PNG overlay hook/label/CTA), `<clip>.edl`, `<clip>.srt`, `markers_<clip>.csv`

| NLE | นำเข้า | ตั้งค่า vertical | หมายเหตุ |
|---|---|---|---|
| **Final Cut Pro** | File › Import › XML… (FCPXML) · ซับ: File › Import › Captions (.srt) | project ใน FCPXML เป็น 1080×1920 แล้ว (ถ้าสร้างเอง: custom 1080×1920, fps ตามต้นฉบับ) | ใช้ Roles: Dialogue / Music / Effects เพื่อ mix และ export stems |
| **DaVinci Resolve** | File › Import › Timeline (FCPXML หรือ EDL) + ลาก .srt เข้า Media Pool → subtitle track | Timeline resolution 1080×1920 (ใช้ vertical) | titles/hook box ทำด้วย Text+ ใน Fusion (บันทึกเป็น template); เกรดสีที่ Color page; Fairlight สำหรับ loudness |
| **Premiere Pro** | File › Import EDL (+ import .srt เป็น captions) | Sequence 1080×1920 | EDL เก็บแค่การตัด (ไม่มีเอฟเฟกต์/ซูม) — จัดเฟรมใหม่เอง |
| **CapCut desktop (Mac)** | ลากวิดีโอจาก kit + นำเข้า .srt ในส่วน captions (ชื่อเมนูอาจต่างตามเวอร์ชัน) | canvas 9:16 | ทำตาม `EDIT_GUIDE.md` ใน kit; PNG overlay วางตำแหน่งไว้แล้ว |

Keyboard-driven finishing (ค่าเริ่มต้น):
- FCP: `Cmd+B` blade ที่ playhead · `Option+[` / `Option+]` trim ต้น/ท้ายถึง playhead · `Q` connect clip (วาง B-roll)
- Resolve: `Cmd+B` razor · `Shift+[` / `Shift+]` trim start/end ถึง playhead · `Cmd+Shift+[`/`]` ripple trim
- Premiere: `Cmd+K` add edit · `Q` / `W` ripple trim ต้น/ท้ายถึง playhead
- J/L-cut เร็ว ๆ: unlink/แยกเสียงแล้ว roll edit เฉพาะแทร็กเสียง (FCP: expand audio `Ctrl+S`; Resolve/Premiere: ปิด linked selection)

หลัง finish ใน NLE: export 1080×1920 H.264 ตามข้อ 8 แล้ว **ตรวจ loudness/สเปกซ้ำ** (−14 LUFS, −1.5 dBTP) ก่อนโพสต์เสมอ — ไฟล์จาก NLE ไม่ได้ผ่าน loudnorm ของ engine; ส่งให้ clip-qa-reviewer ตรวจด้วยตาเหมือนไฟล์ render
