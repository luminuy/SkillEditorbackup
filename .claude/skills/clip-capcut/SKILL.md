# ส่งต่อ CapCut

## เมื่อไหร่ควรใช้ CapCut kit แทน render สำเร็จรูป
| ต้องการ | ทางเลือก |
|---|---|
| โพสต์เลย เร็วที่สุด | `render` ปกติ (ซับ+เอฟเฟกต์ครบในไฟล์) |
| ใช้เพลงติดเทรนด์จากคลังแอป, ฟอนต์/สติกเกอร์/เทมเพลตของ CapCut, ปรับเองทีละจุด | **CapCut kit** |
| คนตัดต่อในทีมใช้ CapCut อยู่แล้ว | **CapCut kit** (`--raw` ถ้าเขาอยากใส่ transition เอง) |

## คำสั่ง
```bash
python3 -m clipstudio capcut <slug>                    # ทุกคลิปใน plan: transition/motion/เสียงเอฟเฟกต์อยู่ในวิดีโอแล้ว ไม่มีตัวหนังสือ
python3 -m clipstudio capcut <slug> --clip 01-aries    # เฉพาะคลิป
python3 -m clipstudio capcut <slug> --raw              # ตัดเปล่า: ไม่มีเอฟเฟกต์เลย (ให้คนตัดต่อทำเองตาม markers)
python3 -m clipstudio capcut <slug> --zip              # + capcut/<id>.zip ต่อคลิป (ส่งเข้ามือถือง่าย)
```
ผลลัพธ์ `projects/<slug>/capcut/<id>/`:
```
<id>_video.mp4      1080x1920 30fps, ตัดเงียบแล้ว, ครอปแล้ว, เสียง -14 LUFS, (ไม่มีซับ/hook/ป้าย)
<id>.srt            ซับทีละบรรทัด ตรงเวลาของคลิปนี้
<id>_words.srt      ซับทีละคำ (ทำซับเด้งทีละคำ)
overlays/*.png      hook, label_01…, cta, watermark — PNG โปร่งใสขนาดเต็มจอ วางแล้วลากให้เต็มจอ ตำแหน่งถูกเอง
sfx/*.wav, sfx.csv  เสียงเอฟเฟกต์ + เวลา
markers.csv         ทุกจังหวะ: cut, transition, เปิดไพ่, เอฟเฟกต์, เสียง + ชื่อเอฟเฟกต์ที่แนะนำใน CapCut
EDIT_GUIDE.md       คู่มือทีละขั้น (ภาษาไทย)
```

## ขั้นตอนใน CapCut (สรุปสำหรับผู้ใช้)
1. New project → นำเข้า `<id>_video.mp4`
2. ซับ — **Desktop**: Text/Captions → Import captions (.srt) · **มือถือ**: นำเข้า .srt ไม่ได้ → ใช้ Auto captions ภาษาไทย (เสียงสะอาดแล้ว ถอดได้แม่น) แล้วแก้คำผิดตาม `<id>.srt`
3. Overlay → Add overlay → PNG ใน `overlays/` → ลากให้เต็มจอ → ตั้งเวลาตามตารางใน EDIT_GUIDE
4. เอฟเฟกต์/transition เพิ่มเติม: ดูคอลัมน์ `capcut` ใน `markers.csv` (ชื่อเมนูในแอปเปลี่ยนตามเวอร์ชัน — ใช้ช่องค้นหาด้วยคำอังกฤษ เช่น Sparkle, Flash, Shake, Zoom)
5. เพลง: จากคลังของแอป (บัญชีธุรกิจต้องใช้ Commercial music) ระดับ ~10–15%
6. Export 1080p 30fps

ชื่อเมนูของ CapCut เปลี่ยนบ่อยตามเวอร์ชัน — เวลาแนะนำผู้ใช้ให้บอกเป็นคำค้นหา ไม่ใช่ตำแหน่งเมนูตายตัว

## ข้อจำกัดที่ต้องบอกผู้ใช้ตามจริง
- ไฟล์โปรเจกต์ CapCut (draft) สร้างอัตโนมัติไม่ได้อย่างน่าเชื่อถือ (รูปแบบไม่เปิดเผยและเข้ารหัสในเวอร์ชันใหม่) — kit นี้คือวิธีที่เสถียรที่สุด
- ถ้าผู้ใช้อยากได้ซับสไตล์เดียวกับ render ของเรา ให้ใช้ render สำเร็จรูป แล้วใช้ CapCut แค่เติมเพลง
- ฟอนต์ Kanit อยู่ใน `assets/fonts/` ติดตั้งในเครื่องได้ (desktop) เพื่อให้ซับเหมือนแบรนด์

## ส่งไฟล์ให้ผู้ใช้
kit อยู่ใน `projects/<slug>/capcut/` — ถ้าผู้ใช้ทำงานบนมือถือ ให้บีบอัดเป็น zip ต่อคลิป หรืออัปโหลดขึ้น Google Drive (connector) เมื่อผู้ใช้อนุญาต
