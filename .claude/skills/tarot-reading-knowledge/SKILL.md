# Tarot Reading Knowledge (ดูดวงไพ่ทาโรต์ → คลิปสั้น)

ข้อมูลไพ่ทั้ง 78 ใบ (สาย Rider–Waite) อยู่ที่ `clipstudio/data/cards.json` และราศี/วันเกิด/คำเรียกกองอยู่ที่ `clipstudio/data/zodiac.json` ใช้สองไฟล์นี้เป็นแหล่งความจริง ห้ามแต่งความหมายไพ่ขึ้นเอง

## 1. ค้นหาไพ่

```bash
python3 -m clipstudio cards --search <คำค้น>          # ค้นใน id, ชื่ออังกฤษ, ชื่อไทย, คีย์เวิร์ด upright/reversed
python3 -m clipstudio cards --search "queen of cups"
python3 -m clipstudio cards --search ราชินีถ้วย
python3 -m clipstudio cards --search tower --json    # ได้ JSON ดิบ (ใช้ต่อในสคริปต์)
```

- `--json` คืนรายการ object ตาม schema ของ cards.json
- `--search` ค้นใน `aliases` ด้วย (คำทับศัพท์/ถอดเสียงเพี้ยน เช่น `ทาวเวอร์`) — ถ้ายังไม่เจอ ดูตารางข้อ 5

Field สำคัญของแต่ละใบ:

| field | ใช้ทำอะไร |
|---|---|
| `id` | kebab-case เช่น `the-sun`, `ace-of-cups`, `knight-of-pentacles` — ใช้ใน plan |
| `name_th` | ชื่อไทยสั้น ไม่มีคำว่า "ไพ่" (เช่น `ราชินีดาบ`) — ตอนขึ้นจอให้เติม "ไพ่" เองถ้าต้องการ |
| `upright` / `reversed` | คีย์เวิร์ดหัวตั้ง / กลับหัว |
| `love`, `money_work` | ประโยคสั้นสำหรับแคปชันหัวข้อความรัก / งานเงิน (ความหมายหัวตั้ง) |
| `overlay` | แท็กไลน์ ≤ 18 ตัวอักษร สำหรับเบิร์นบนวิดีโอ (หัวตั้ง) |
| `mood` | `positive` / `neutral` / `challenging` — ใช้เลือกโทนสี/เพลง และระวังไม่ขายความกลัว |
| `element` | ไฟ / น้ำ / ลม / ดิน |
| `aliases` | คำทับศัพท์/ชื่อเรียกอื่นที่พูดจริง (เช่น `ทาวเวอร์`, `ควีนออฟคัพ`) ใช้แก้ transcript |

ชุดไพ่เล็ก: ถ้วย (Cups, น้ำ) · ไม้เท้า (Wands, ไฟ — บางช่องเรียก "ไม้คทา") · ดาบ (Swords, ลม) · เหรียญ (Pentacles, ดิน)
ลำดับ: เอซ 1 … สิบ 10, เพจ 11, อัศวิน 12, ราชินี 13, ราชา 14

## 2. ติดป้ายจังหวะเปิดไพ่ในแผนคลิป

เมื่อผู้อ่านไพ่ "เปิด" หรือ "พูดชื่อ" ไพ่ ให้เพิ่ม label item ในแผนคลิป:

```json
{"at": 312.4, "card": "the-tower", "reversed": false, "duration": 3}
```

- `at` = วินาทีใน **ไฟล์ต้นฉบับ** (ไม่ใช่เวลาในคลิปที่ตัดแล้ว) ตั้งให้ตรงจังหวะที่ไพ่โผล่ในภาพหรือคำแรกของชื่อไพ่ ถ้าพูดชื่อหลังเปิดไพ่ ให้ใช้เวลาที่เปิด
- `reversed: true` เฉพาะเมื่อผู้อ่านพูดชัดว่า "กลับหัว / reversed / กลับด้าน" ช่องที่ไม่อ่านไพ่กลับหัวให้เป็น `false` เสมอ
- `duration` ปกติ 2.5–4 วินาที ไม่ควรทับ label ใบถัดไป
- ถ้าเปิดหลายใบรัว ๆ ให้ label ทีละใบตามลำดับ อย่ารวม
- ไม่แน่ใจว่าเป็นใบไหน (เสียงไม่ชัด/ภาพไม่เห็น) → ห้ามเดา ให้ใส่ในรายงานว่า "ต้องตรวจ" พร้อมเวลา
- ไพ่ออราเคิล / เลอนอร์มองด์ ไม่มีใน cards.json — อย่าจับคู่ให้ตรงกับไพ่ทาโรต์

## 3. รูปแบบคอนเทนต์ยอดนิยม และคลิปที่ "แข็ง"

| รูปแบบ | ตัดคลิปอย่างไร | จุดที่ต้องมี |
|---|---|---|
| **เลือกกอง / pick-a-card** | 1 คลิปต่อ 1 กอง + คลิปเปิด (ให้คนเลือกกอง) แยกอีกอัน | 1–3 วินาทีแรกบอกเลขกองชัด ๆ, มีภาพกองไพ่ให้หยุดดู, จบด้วยใบที่แรงที่สุด |
| **ดวง 12 ราศี (รายสัปดาห์/รายเดือน)** | 1 คลิปต่อราศี ตัดตั้งแต่ประโยคที่เอ่ยชื่อราศีจนก่อนขึ้นราศีถัดไป | ชื่อราศีบนจอตลอด (ใช้ `name_th`), ช่วงวันที่ (ระบุว่าตำราไทยหรือสากล), ไพ่หลัก 1–3 ใบ |
| **ดวงความรัก / คนโสด / คนมีคู่** | แยกคลิป "คนโสด" กับ "คนมีคู่" ถ้าผู้อ่านแยกพูด | ประโยค `love` ของไพ่เป็นแคปชันได้, hook ต้องบอกว่าเหมาะกับใคร |
| **ข้อความจากจักรวาล** | คลิปเดียว 15–45 วิ ตัดเฉพาะ "ข้อความ" ที่ฟังจบแล้วอิ่ม | ประโยคปิดที่อบอุ่น ใช้ได้กับทุกคน (timeless) |
| **ดวงรายวันตามวันเกิด** | 1 คลิปต่อวันเกิด (รวมพุธกลางคืน/ราหู) | สีประจำวันจาก `zodiac.json` ใช้เป็นธีมสีกราฟิกได้ |
| **ไลฟ์ดูดวง** | ตัด "ช่วงตอบคำถาม" ที่เป็นเรื่องทั่วไป + ช่วงเปิดไพ่ที่คนดูกรี๊ด | ตัดชื่อ/ข้อมูลส่วนตัวของผู้ชมออก, ไม่ตัดช่วงขาย/โอนเงิน |

คลิปแข็งโดยทั่วไป:
- **Card reveal moment**: มือพลิกไพ่ + ชื่อไพ่ขึ้นจอ + overlay ภายใน 1 วินาที
- **ข้อความสากล** ที่คนดูแคปไปโพสต์ต่อได้ ("สิ่งที่รอมาจะมาในแบบที่ไม่คาดคิด")
- **ความเฉพาะเจาะจงแต่ไม่การันตี** ("มีแววได้ข่าวดีเรื่องเอกสาร" ดีกว่า "ได้เงินแน่นอน")
- เริ่มคลิปที่ประโยคที่มีพลัง ไม่ใช่ "สวัสดีค่ะ วันนี้เรามา…"
- ความยาว: TikTok/Reels 20–60 วิ, Shorts ≤ 60 วิ (คลิปยาวกว่านี้ให้เช็กสเปกแพลตฟอร์มปัจจุบัน)

## 6. ราศี วันเกิด และการเลือกกอง

`clipstudio/data/zodiac.json` มี:
- `signs[]` — ชื่อไทยเต็ม/สั้น, `aliases` (คำพูดจริง เช่น กันยา, ตุล, กุมภ, มิถุน, กรกฏ, ราศีพิจิตร), `ambiguous_aliases` (คำที่ชนกับชื่อเดือน/จังหวัด ใช้เมื่อบริบทชัด), ช่วงวันที่แบบสากล (`dates_western`) และแบบไทย/สุริยยาตร (`dates_thai_sidereal`) — **ถามหรือดูจากคลิปว่าช่องใช้ระบบไหน อย่าผสมกัน**
- `weekdays[]` — 7 วัน + `wednesday-night` (พุธกลางคืน/ราหู) พร้อมสีประจำวัน
- `piles` — คำเรียกเลขกอง (`number_words`), ซ้าย/กลาง/ขวา, และ A/B/C/D

ใช้ aliases เหล่านี้หาจุดเริ่มของแต่ละช่วงใน transcript (เช่น "ต่อไปชาวกันย์นะคะ" = จุดตัดของราศีกันย์)
