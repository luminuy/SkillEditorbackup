# เช็กลิสต์นโยบายแพลตฟอร์มและจริยธรรม: คอนเทนต์ดูดวง/ไพ่ทาโรต์

TikTok, YouTube และ Meta (Facebook/Instagram) **อนุญาต** คอนเทนต์ดูดวง โหราศาสตร์ และความเชื่อทางจิตวิญญาณ ปัญหาเกิดจาก "วิธีนำเสนอ" มากกว่าตัวหัวข้อ
เอกสารนี้เป็นแนวปฏิบัติ ไม่ใช่การอ้างถ้อยคำนโยบาย นโยบายแพลตฟอร์มเปลี่ยนบ่อย ถ้าจะอ้างข้อกำหนดเฉพาะ ให้ตรวจ Community Guidelines ฉบับปัจจุบันก่อน

## เช็กลิสต์ก่อนโพสต์ (ทุกคลิป)

- [ ] **ไม่นำเสนอคำทำนายเป็นข้อเท็จจริงแบบการันตี** — ใช้ "มีแวว", "ไพ่ชี้ว่า", "พลังงานช่วงนี้" แทน "แน่นอน", "100%"
- [ ] **ไม่ให้คำแนะนำแพทย์ กฎหมาย หรือการเงินการลงทุนเฉพาะเจาะจง** — ไม่บอกให้หยุดยา/ไม่ไปหาหมอ, ไม่ฟันธงคดี, ไม่บอกให้ซื้อหุ้น/คริปโต/ลงทุนตัวไหน
- [ ] **ไม่ขู่ ไม่ขายความกลัว ไม่ใช้ข้อความลูกโซ่** — "ถ้าไม่แชร์จะโชคร้าย", "พิมพ์ 'รับ' ไม่งั้นพลาด" เข้าข่ายหลอกให้มีส่วนร่วม (engagement bait) ซึ่งแพลตฟอร์มมักลดการมองเห็น
- [ ] **ไม่มีเลขเด็ด หวย หรือการพนัน** ในเสียง ข้อความบนจอ แคปชัน แฮชแท็ก หรือปก (ดูหัวข้อด้านล่าง)
- [ ] **Hook/ปก/ชื่อคลิปตรงกับเนื้อหาจริง** — ไม่ขึ้น "ถูกรางวัลใหญ่!" หรือ "เรื่องร้ายกำลังมา" ถ้าในคลิปไม่ได้พูด
- [ ] **ไม่ฟันธงเรื่องบุคคลจริง** (ดารา นักการเมือง คนดูที่ระบุตัวได้) ในเชิงเสียหาย เช่น "เขานอกใจแน่นอน"
- [ ] **ไลฟ์: ตัดชื่อ เบอร์ วันเดือนปีเกิด หน้าโปรไฟล์ ของผู้ชมออก** ก่อนนำมาทำคลิปสั้น (ข้อมูลส่วนบุคคล / PDPA)
- [ ] **เพลงและภาพมีสิทธิ์ใช้** — ใช้เพลงจากคลังของแพลตฟอร์ม (บัญชีธุรกิจควรใช้คลังเพลงเชิงพาณิชย์ เช่น Commercial Music Library ของ TikTok), ไม่ใช้เพลงดังที่ไม่มีสิทธิ์เมื่อข้ามแพลตฟอร์ม, ไม่ตัดคลิปของช่องอื่นมาใช้
- [ ] **ภาพไพ่** — สำรับ Rider–Waite ต้นฉบับ (1909) ถือว่าเป็นสาธารณสมบัติในหลายประเทศ แต่สำรับรุ่นใหม่/ภาพวาดใหม่มีลิขสิทธิ์ของผู้ออกแบบ ใช้สำรับที่ช่องถ่ายเองได้ ห้ามดึงภาพไพ่จากเว็บไปแปะ
- [ ] **มี disclaimer** อย่างน้อยแบบสั้นในแคปชัน หรือในโปรไฟล์ช่อง

## เลขเด็ด / หวย / การพนัน

- ในไทย การพนันและการโฆษณาชักชวนเล่นพนันออนไลน์ผิดกฎหมาย (พ.ร.บ.การพนัน พ.ศ. 2478 และกฎหมายที่เกี่ยวข้อง) หวยใต้ดินผิดกฎหมาย
- แพลตฟอร์มหลักทั้งหมดจำกัดคอนเทนต์ที่ส่งเสริมการพนัน/ชักชวนเสี่ยงโชค และมักจำกัดการมองเห็นหรือลบคลิปที่มีเลขเด็ดหรือลิงก์เว็บพนัน
- แนวปฏิบัติของ clip studio: **ไม่ตัด ไม่ขึ้นจอ ไม่ใส่แคปชัน** ช่วงที่ผู้อ่านไพ่ "ให้เลข" แม้ในไลฟ์ต้นฉบับจะมี ให้ตัดช่วงนั้นทิ้งและแจ้งในรายงาน
- ไม่ตอบรับการ "สปอนเซอร์" จากเว็บพนัน/เว็บหวยออนไลน์ในแคปชันหรือลิงก์

## การรับดูดวงแบบเสียเงิน

- การประกาศรับดูดวงไม่ผิด แต่ **อย่าให้คลิปดูเหมือนหลอกโอน**: หลีกเลี่ยง "โอนก่อนภายใน 10 นาทีเท่านั้น", "แก้กรรมด่วน ไม่ทำจะแย่"
- อย่าขาย "พิธีแก้ดวง" หรือวัตถุมงคลโดยอ้างผลทางสุขภาพ/การเงินแบบรับประกัน (เสี่ยงทั้งนโยบายแพลตฟอร์มและกฎหมายคุ้มครองผู้บริโภค/โฆษณา)
- ช่องทางรับงานควรระบุชัดในโปรไฟล์ และเตือนผู้ติดตามเรื่อง **บัญชีปลอมแอบอ้าง** ที่ทักไปขอเงิน (เป็นปัญหาที่พบบ่อยมากในช่องดูดวง)
- แพลตฟอร์มบางแห่งจำกัดการชักชวนทำธุรกรรมนอกแพลตฟอร์มผ่านคอมเมนต์/ไลฟ์ — ใช้ลิงก์ในโปรไฟล์แทนการพิมพ์เลขบัญชีบนจอ
- ไม่นำเสนอบริการกับผู้ใช้ที่เห็นได้ชัดว่าเป็นผู้เยาว์

## หัวข้อที่ต้องระวังเป็นพิเศษ

- **สุขภาพ/ตั้งครรภ์/อายุขัย/ความตาย**: ไม่ทำนายการเจ็บป่วยหรือการเสียชีวิตของใคร ไพ่ Death ให้อธิบายเป็น "การเปลี่ยนแปลง/จบบทเดิม"
- **สุขภาพจิต**: ถ้าผู้ชมในไลฟ์พูดถึงการทำร้ายตัวเอง อย่าตัดมาทำคลิป และหากช่องอยากใส่ข้อความ ให้แนะนำสายด่วนสุขภาพจิต 1323
- **ความรุนแรงในความสัมพันธ์**: อย่าใช้ไพ่แนะนำให้ "อดทนต่อ" ในความสัมพันธ์ที่มีความรุนแรง
- **การเมือง/ภัยพิบัติ**: หลีกเลี่ยงการทำนายเหตุการณ์ร้ายระดับประเทศ เสี่ยงเป็นข้อมูลเท็จที่ทำให้ตื่นตระหนก

## Disclaimer ภาษาไทย

**แบบสั้น (แคปชัน / มุมจอ)**
- `ดูเพื่อความบันเทิงและเป็นแนวทาง โปรดใช้วิจารณญาณ`
- `คำทำนายเป็นเพียงแนวทาง ชีวิตคุณกำหนดได้เอง`
- `#ดูเพื่อความบันเทิง ไม่ใช่คำแนะนำทางการแพทย์/การเงิน`

**แบบยาว (คำอธิบายคลิป / โปรไฟล์ / ปักหมุด)**
> คอนเทนต์นี้เป็นการอ่านไพ่ทาโรต์แบบทั่วไป (general reading) เพื่อความบันเทิงและเป็นแนวทางในการทบทวนตัวเอง ไม่สามารถใช้แทนคำแนะนำจากแพทย์ นักกฎหมาย หรือที่ปรึกษาทางการเงินได้ ผลลัพธ์ในชีวิตขึ้นอยู่กับการตัดสินใจของคุณเอง โปรดใช้วิจารณญาณในการรับชม ช่องนี้ไม่มีนโยบายขอเงินผ่านข้อความส่วนตัว ระวังบัญชีแอบอ้าง

## คำเสี่ยง → คำที่ปลอดภัยกว่า

| คำ/ประโยคเสี่ยง | ปัญหา | ใช้แทน |
|---|---|---|
| รวยแน่นอน 100% | การันตีผลทางการเงิน | มีแววการเงินดีขึ้น |
| เขากลับมาแน่นอน | การันตีผล | ไพ่บอกว่ายังมีโอกาสได้คุยกันอีก |
| ถ้าไม่แชร์จะโชคร้าย | ขู่/ลูกโซ่ | ถ้าตรงกับคุณ เซฟเก็บไว้ได้เลย |
| พิมพ์ "รับ" ภายใน 1 นาที | engagement bait | ใครรู้สึกว่าตรง คอมเมนต์เล่าให้ฟังได้นะ |
| เลขเด็ดงวดนี้จากไพ่ | พนัน/หวย | (ตัดทิ้ง ไม่มีคำแทน) |
| ราศีนี้เจอเรื่องร้ายหนัก | ขายความกลัว | ราศีนี้ไพ่ชวนให้ระวังเรื่อง… |
| ไพ่บอกว่าป่วยหนัก | ทำนายสุขภาพ | ช่วงนี้ดูแลสุขภาพและพักผ่อนให้พอ |
| ไม่ต้องไปหาหมอ ไพ่บอกว่าหาย | คำแนะนำการแพทย์ | ไพ่เป็นกำลังใจ แต่ควรปรึกษาแพทย์ด้วย |
| ลงทุนตัวนี้เลย ไพ่ให้มา | คำแนะนำการลงทุน | ช่วงนี้เหมาะกับการวางแผนการเงินอย่างรอบคอบ |
| ฟ้องเลย ชนะแน่ | คำแนะนำกฎหมาย | เรื่องเอกสาร/สัญญาควรปรึกษาผู้เชี่ยวชาญ |
| ต้องแก้กรรมด่วน ไม่งั้นแย่ | ขายความกลัว/ขายบริการ | ถ้าอยากดูเจาะลึก ดูช่องทางในโปรไฟล์ |
| โอนก่อนภายในวันนี้เท่านั้น | ลักษณะคล้ายมิจฉาชีพ | รายละเอียดการดูดวงส่วนตัวอยู่ในโปรไฟล์ |
| เขานอกใจคุณแน่นอน | ฟันธงตัวบุคคล | ไพ่ชวนให้คุยกันตรง ๆ เรื่องความไว้ใจ |
| คุณจะตายเร็ว / ไพ่ Death คือความตาย | ทำนายความตาย | ไพ่ Death หมายถึงการจบบทเก่า เริ่มบทใหม่ |
| แม่นที่สุดในไทย | อ้างเกินจริง | หลายคนบอกว่าตรงมาก (ถ้ามีคอมเมนต์จริง) |
