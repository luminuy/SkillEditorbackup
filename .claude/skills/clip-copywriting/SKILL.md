# แคปชัน & แฮชแท็ก (Copywriter)

อินพุต: `plan.json` (hook, notes), `transcript.txt` (ช่วงของคลิป), ผลจาก trend-scout (ถ้ามี), `channel.config.json`
เอาต์พุต: `projects/<slug>/copy/<clip-id>.json` — หนึ่งไฟล์ต่อคลิป

```json
{
  "clip_id": "01-aries",
  "hook": "ราศีเมษ คนที่คิดถึงกำลังจะทักมา",
  "platforms": {
    "tiktok":   {"caption": "…", "hashtags": ["#ดูดวง", "#ราศีเมษ", "#ไพ่ทาโรต์", "#ดูดวงความรัก", "#tarot"]},
    "reels":    {"caption": "…", "hashtags": ["…"]},
    "shorts":   {"title": "… #shorts", "description": "…", "hashtags": ["#shorts", "…"]},
    "facebook": {"caption": "…", "hashtags": ["…"]}
  },
  "pinned_comment": "คอมเมนต์ 'รับพลัง' ถ้าคุณคือราศีเมษ 💫",
  "posting_slot": "2026-09-27 19:30"
}
```
ใส่เฉพาะแพลตฟอร์มใน `channel.config.json` → `platforms`; `posting_slot` ไม่ใส่ก็ได้ (review จะจัดให้ตาม `posting.slots`)

## โครงแคปชันที่ได้ผล
1. **บรรทัดแรก = hook ที่ต่างจากบนจอเล็กน้อย** (แพลตฟอร์มตัดแคปชันหลังบรรทัดแรก ๆ)
2. 1–2 บรรทัดเนื้อหา: ไพ่ที่ออก + ความหมายแบบสั้น (อ่านจาก `cards --id <id>`)
3. **ชวนมีส่วนร่วม** ที่ตอบง่าย: "คอมเมนต์ราศีของคุณ", "พิมพ์ 'รับ' ถ้าตรง", "แท็กเพื่อนราศีเดียวกัน"
4. disclaimer สั้น (niche ดูดวง): "ดูดวงเพื่อเป็นแนวทาง โปรดใช้วิจารณญาณ"
5. แฮชแท็กท้ายสุด

## กติกาแต่ละแพลตฟอร์ม
| | ความยาวแนะนำ | แฮชแท็ก | หมายเหตุ |
|---|---|---|---|
| TikTok | 1–3 บรรทัด (สั้นดีกว่า) | 3–5 (ผสมกว้าง+เฉพาะ) | ใส่คีย์เวิร์ดค้นหาในประโยค (TikTok search) |
| Reels | 2–4 บรรทัด | 3–5 | ย่อหน้าอ่านง่าย, อิโมจิพอประมาณ |
| Shorts | title ≤ 100 ตัวอักษร (ดีที่สุด ≤ 60) | 2–4 รวม #shorts | title = คีย์เวิร์ด + ผลลัพธ์; description มีคีย์เวิร์ดซ้ำ |
| Facebook | 1–3 บรรทัด | 2–5 | ภาษาอบอุ่นเป็นกันเอง, ชวนแชร์ให้เพื่อน (ไม่ขู่) |

อิโมจิใช้ได้ในแคปชัน (ไม่ใช่บนวิดีโอ). niche ดูดวง: ชุดแฮชแท็กและ compliance อยู่ใน skill `tarot-reading-knowledge`
(`references/hashtags-th.md`, `references/compliance-th.md`) — อ่านก่อนเขียนทุกครั้ง

## ห้าม
- สัญญาผลแน่นอน ("100%", "การันตี"), เลขเด็ด/หวย, ขู่ให้แชร์, คำแนะนำการเงิน/สุขภาพ
- แคปชันที่ไม่ตรงกับเนื้อหาในคลิป
- แฮชแท็กที่ไม่เกี่ยวข้องเพื่อเรียกยอด (#fyp มากกว่า 1 อัน, แท็กดาราที่ไม่เกี่ยว)

## ตารางโพสต์
หลังเขียนครบ: `python3 -m clipstudio review <slug> [--start 2026-09-28]` → `schedule.csv`

ต้องการ Excel → skill `xlsx`; ต้องการเตือนในปฏิทิน → Google Calendar connector (ถามผู้ใช้ก่อนสร้าง event)
