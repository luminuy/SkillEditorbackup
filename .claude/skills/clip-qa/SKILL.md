# QA ก่อนโพสต์

## 1. ตรวจอัตโนมัติ
```bash
python3 -m clipstudio qa <slug>          # → qa.md / qa.json ; exit 1 ถ้ามี fail
```
ระดับ: `fail` = ห้ามส่ง · `warn` = ต้องแก้หรืออธิบาย · `info` = ข้อสังเกต

## 2. ตรวจด้วยตา (ทุกคลิป — เครื่องมือตรวจไม่เห็นสิ่งเหล่านี้)
```bash
python3 -m clipstudio snapshot <slug> <clip-id>   # แล้ว Read projects/<slug>/work/snap_<id>.jpg
```
- ซับ/hook/label ไม่ทับกันเอง ไม่ทับหน้า ไม่อยู่ในโซน UI (บน 10%, ล่าง 20%, ขวา 12%)
- เฟรมแรก (0.6s) มี hook และภาพน่าสนใจ — นี่คือสิ่งที่คนเห็นก่อนตัดสินใจเลื่อน
- ไม่มีขอบดำ/ภาพยืด/หน้าถูกตัดครึ่ง
- ปก (`thumbs/`) อ่านออก ตรงกับเนื้อหา

## 3. ตรวจเนื้อหา
- อ่าน transcript ช่วงของคลิป (`transcript.txt` + เวลาใน plan) เทียบกับ hook/แคปชัน: **สัญญาอะไรไว้ คลิปต้องให้สิ่งนั้น**
- ซับสะกดถูก โดยเฉพาะชื่อไพ่/ราศี/ชื่อเฉพาะ
- ไม่มี: เลขเด็ด/หวย, การันตีผล, การทำนายความตาย/โรค, คำแนะนำลงทุน, ข้อความขู่ให้แชร์, ข้อมูลส่วนตัวคนอื่น
- niche ดูดวง: เช็กลิสต์เต็มใน skill `tarot-reading-knowledge` → `references/compliance-th.md`
- เพลงประกอบ: ต้องเป็นไฟล์ที่มีสิทธิ์ใช้ (ถ้าไม่แน่ใจ → แนะนำให้ใส่เพลงจากคลังในแอปตอนโพสต์แทน)

## 4. สั่งแก้
เขียนผลเป็นตาราง: clip · สถานะ (✅/⚠️/❌) · ปัญหา · ส่งกลับให้ใคร (transcriber/producer/editor/copywriter/thumbnail) · วิธีแก้ที่แนะนำชัด ๆ
อย่าแก้ไฟล์ของ agent อื่นเอง ยกเว้นผู้กำกับสั่ง; เมื่อแก้แล้วรัน `qa` ซ้ำเฉพาะคลิปนั้น (`--clip <id>`)
