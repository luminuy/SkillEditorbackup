# ปก & Thumbnail

## 1. หาเฟรมที่ดีที่สุด (ต้อง "ดู" จริง)
```bash
python3 -m clipstudio frames <slug> --times 20.5,21.5,22.5,23.5,39.8,40.5 --tag c01   # ช่วงที่ story-producer ระบุ
```
Read `projects/<slug>/work/frames_c01.jpg` แล้วเลือกเฟรมที่:
- เห็นไพ่ใบสำคัญชัด (ไม่เบลอจากการเคลื่อนไหว) หรือสีหน้าผู้พูดมีอารมณ์ (ยิ้ม/ตกใจ) — ไม่หลับตา ไม่อ้าปากค้าง
- มีพื้นที่ว่างสำหรับข้อความ (ข้อความอยู่ส่วนบน 1/3)
- คอนทราสต์ดี สีสด

## 2. สร้าง
```bash
# ปกแนวตั้ง (เลือกเป็น cover ในแอป TikTok/IG)
python3 -m clipstudio thumbnail <slug> --clip 01-aries --time 22.6 --title "ราศีเมษ คนที่คิดถึงกำลังจะทักมา" --sub "ดวงความรักรายสัปดาห์"
# YouTube 16:9 (ของคลิปยาวต้นฉบับ หรือ Shorts ที่อยากตั้งปก)
python3 -m clipstudio thumbnail <slug> --clip 01-aries --time 22.6 --size 1280x720 --title "ราศีเมษ มีข่าวดี" --sub "The Lovers"
```
`--x 0.3` เลื่อนจุดครอปไปทางซ้าย (0–1) เมื่อสิ่งสำคัญไม่อยู่กลางภาพ

ไฟล์: `projects/<slug>/thumbs/<clip>_<size>.jpg` → Read เพื่อตรวจทุกครั้ง

## หลักข้อความบนปก
- 2–5 คำ, ใหญ่, อ่านได้ในขนาด thumbnail เล็กบนมือถือ — สั้นกว่า hook ได้
- หัวข้อ + ผลลัพธ์ ("ราศีเมษ มีข่าวดี", "กอง 2 เขากำลังกลับมา") — ไม่หลอก ไม่ขู่
- `--sub` ใช้ชื่อไพ่หลักหรือช่วงเวลา ("สัปดาห์นี้", "The Sun")
- ไม่มีอิโมจิในข้อความบนภาพ

## ทางเลือก
- ถ้ามี Canva connector และผู้ใช้มี template แบรนด์ → ใช้ Canva autofill แล้ว export มาเป็น `thumbs/<clip>_canva.jpg`
- ทำหลายแบบ (A/B) ได้: เปลี่ยน `--time` / `--title` แล้วตั้งชื่อ `--clip 01-aries-b`
