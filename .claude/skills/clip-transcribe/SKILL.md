# ถอดเสียง + พิสูจน์อักษร

## 1. ถอดเสียง
```bash
python3 -m clipstudio transcribe <slug>                       # faster-whisper large-v3-turbo, ภาษาจาก config
python3 -m clipstudio transcribe <slug> --model large-v3      # แม่นขึ้นเล็กน้อย ช้ากว่า ~2x
python3 -m clipstudio transcribe <slug> --srt input/x.srt     # นำเข้าซับที่มีอยู่ (ไม่ต้องใช้ whisper)
```
- CPU 4 คอร์: turbo ใช้เวลาประมาณ 0.7× ความยาวคลิป (ครั้งแรกโหลดโมเดล ~1.6 GB)
- engine ใส่ vocabulary prompt และแก้คำผิดที่พบบ่อยจาก `presets/<niche>.json` → `asr.fixes` ให้อัตโนมัติ
- ผลลัพธ์: `transcript.txt` (อ่านง่าย มีเลข segment `#id`), `transcript.json` (ระดับคำ), `transcript.srt`

## 2. พิสูจน์อักษร (ขั้นที่สำคัญที่สุด — ห้ามข้าม)
อ่าน `projects/<slug>/transcript.txt` ทั้งไฟล์ แล้วแก้เฉพาะ segment ที่ผิด:
```bash
python3 -m clipstudio fix <slug> 3 "ชาวราศีเมษ ไพ่ใบแรกที่ออกมาคือไพ่ The Lovers ค่ะ" 7 "ไพ่ใบที่ 2 คือ Ten of Cups"
```
`fix` เก็บเวลาเดิมของ segment และกระจายเวลาคำใหม่ให้เอง — **อย่าแก้ transcript.json ด้วยมือ**

สิ่งที่ Whisper ไทยพลาดบ่อย (จากการทดสอบจริง):
| ได้มา | ที่ถูก | หมายเหตุ |
|---|---|---|
| ราสี, ไพ้, ภาย/ให้ (ขึ้นต้นประโยค) | ราศี, ไพ่ | ภาย/ให้ = "ไพ่" ที่ถูกตัดวรรณยุกต์ |
| เมตร, พริษษษ, มิถุ่น | เมษ, พฤษภ, มิถุน/เมถุน | ชื่อราศีเพี้ยนเสียง |
| THE LOVE WORK, 10-Off คับ | The Lovers, Ten of Cups | ชื่อไพ่อังกฤษสำเนียงไทย → ตรวจกับ `cards --search` |
| คนโสตร/คนโซต | คนโสด | |
| สดสัย, กำวน, เกิดครึ่ง | สดใส, กังวล, เกิดขึ้น | คำพ้องเสียงทั่วไป — แก้ตามบริบท |
| segment ซ้ำ/แตก | รวมความหมายให้ตรงเสียง | segment หนึ่งอาจเลื่อนไปอีก id — ดูเวลาประกอบเสมอ |

หลัก: แก้ให้ **ตรงกับที่พูด** ไม่ใช่เรียบเรียงใหม่; ตัวเลขไทยพูดเป็นคำ ("สอง") ให้เขียนเป็นเลขอารบิกได้ถ้าช่วยอ่าน;
คำลงท้าย (ค่ะ/นะคะ) เก็บไว้ — เป็นเสน่ห์ของผู้พูด; คำหยาบ/ข้อมูลส่วนตัว (ชื่อจริง, เบอร์) ให้แจ้ง story-producer เพื่อตัดทิ้ง

## 3. ส่งต่อ
รายงานสั้น ๆ: จำนวน segment, จำนวนที่แก้, คำที่ไม่แน่ใจ (พร้อมเวลา) และคำที่ควรเพิ่มใน `asr.fixes` ของ preset (เพื่อรอบหน้าไม่ต้องแก้ซ้ำ — เพิ่มเฉพาะคู่ที่ไม่มีทางเป็นคำอื่น)
