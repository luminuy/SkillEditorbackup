# เพลงประกอบ

วางไฟล์เพลงที่ **มีสิทธิ์ใช้** ไว้ที่นี่ (ไม่ถูก commit ขึ้น git) แล้วอ้างอิงใน plan.json: `"music": "assets/music/calm-piano.mp3"`
หรือเป็นค่าเริ่มต้นใน `channel.config.json` → `audio.music`

แหล่งที่ปลอดภัย: YouTube Audio Library, เพลงที่ซื้อ license, เพลงที่แต่งเอง
เพลงติดลิขสิทธิ์/เพลงฮิต → อย่าฝังในไฟล์ ให้เลือกเพลงจากคลังของแอป (TikTok/IG) ตอนโพสต์แทน
engine จะลดเสียงเพลงอัตโนมัติเมื่อมีเสียงพูด (ducking) และ fade in/out ให้
